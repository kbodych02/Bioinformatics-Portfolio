# RNA-Seq Transcriptomics Pipeline: From Raw Reads to Functional Enrichment 🧬📊

## Project Overview
This repository contains a full-stack transcriptomics pipeline demonstrating the end-to-end analysis of Next-Generation Sequencing (RNA-Seq) data. The project is split into two industry-standard phases: an automated Bash pipeline for "upstream" data processing (mapping and counting), and an R-based "downstream" script for Differential Expression (DE) analysis and Gene Ontology (GO) pathway enrichment.

## Dataset
* **Organism:** *Saccharomyces cerevisiae* (Yeast)
* **Reference Genome & Annotation:** Ensembl (R64-1-1)
* **Raw Reads:** European Nucleotide Archive (ENA) - Accession SRR453566
* *Note: Due to GitHub's file size limits, raw `.fastq.gz` reads and heavy `.bam` alignment files are not hosted in this repository. The provided scripts are fully reproducible given the standard input data.*

## Technologies & Tools Used
* **Upstream (Bash / Linux):** `FastQC`, `Trimmomatic`, `HISAT2`, `Samtools`, `featureCounts`
* **Downstream (R / Bioconductor):** `DESeq2`, `ggplot2`, `clusterProfiler`, `org.Sc.sgd.db`

## Workflow Architecture

### Phase 1: Upstream Processing (`Upstream_pipeline.sh`)
1. **Quality Control & Trimming:** Raw paired-end reads underwent QC via FastQC. Adapters and low-quality bases were removed using Trimmomatic (Sliding window 4:20), successfully handling `phred33` encoded legacy data to achieve a >93% read survival rate.
2. **Splice-Aware Mapping:** High-quality reads were mapped to the yeast reference genome using HISAT2, achieving an excellent **87.75% overall alignment rate**. 
3. **Quantification:** BAM files were sorted via Samtools and processed using `featureCounts` to generate a robust gene expression count matrix (`clean_counts.csv`).

### Phase 2: Downstream Analysis (`Downstream_analysis.R`)
1. **Differential Expression:** The count matrix was ingested into `DESeq2`. Statistical modeling and filtering were applied to identify Differentially Expressed Genes (DEGs) based on strict thresholds (FDR < 0.05, |Log2FC| > 1).
2. **Data Visualization:** Generated professional, publication-ready Volcano plots (`ggplot2`) to visualize expression variance and statistical significance across the dataset.
3. **Functional Annotation (GO):** Extracted high-confidence DEGs and utilized `clusterProfiler` to perform Gene Ontology (GO) enrichment analysis, translating lists of mutated genes into meaningful biological processes.
